## What I'm building

### With Alia

**With Alia** is a public Android app built around one continuing digital personality rather than a collection of interchangeable characters.

> **One personality. Millions of unique relationships.**

Alia is designed to remember meaningful details, continue conversations across sessions, preserve a stable identity, and develop selected preferences over time while building a different relationship with each person.

Current product areas include:

- long-term conversational memory
- short-term continuity and recent-context handling
- persistent identity and a developing Living Self
- Russian and English interaction
- relationship-aware personalization
- emotional UX and model behavior
- safety-aware memory boundaries
- real-user feedback and production iteration
